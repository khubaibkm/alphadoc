# Installing AlphaSaaS Chrome Extension via Google Admin Console

## Prerequisites

- **Admin access** to the Google Admin Console  
- The **Extension ID**  
- The **URL** where the extension is hosted  

## Steps

### 1. Access the Google Admin Console

- Log in to your **Google Admin Console**  
- From the left-hand navigation menu, go to:  
  `Devices > Chrome > Apps & extensions` 

  ![Enable Developer Mode](/images/googleadmin/Picture34.png) 

---

### 2. Navigate to Add Extension by ID

- In the **Apps & extensions** section, choose the appropriate **organizational unit (OU)** if necessary  
- Click the **Add** button in the bottom-right corner  
- Select **Add Chrome app or extension by ID** from the dropdown menu  

  ![Enable Developer Mode](/images/googleadmin/Picture35.png) 

  ![Enable Developer Mode](/images/googleadmin/Picture36.png) 

---

### 3. Select Source

- A popup will appear to add an extension by its ID  
- In the **Extension ID** field, enter the extension's unique ID (provided by AlphaSaaS)  

  ![Enable Developer Mode](/images/googleadmin/Picture37.png) 

---

### 4. Choose Source (Custom URL or Chrome Web Store)

- In the dropdown below the Extension ID field, select **From a custom URL**  
- Enter the **URL** where the extension is hosted (provided by AlphaSaaS)  

  ![Enable Developer Mode](/images/googleadmin/Picture38.png) 

---

### 5. Complete the Installation

- Once you've entered the ID and the URL, click **Save**  
- The extension will be added to your organization's Chrome devices based on your OU selection  

---

### 6. Verify Installation

- After installation, verify that the extension appears under the **Apps & extensions** list for the chosen OU  
- Ensure the extension is being deployed correctly to users' devices
