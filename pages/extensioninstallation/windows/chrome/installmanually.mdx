# Installing AlphaSaaS Chrome Extension Manually

## Steps

1. **Download the required files**:

   - [alphadiscovery-extension1.crx.zip](https://alphasaas-generated-extensions.s3.ap-south-1.amazonaws.com/extension%2BWhitelistReg/alphadiscovery-extension_v1.0.0.9.crx)
   - [ extensionWhitelist.reg](https://alphasaas-generated-extensions.s3.ap-south-1.amazonaws.com/extension%2BWhitelistReg/extensionWhitelist.reg)  
     (These are shared with you via email)

---

2. **Unzip the `.crx.zip` file**:

   - Extract the contents of `alphadiscovery-extension1.crx.zip`.

   ![Enable Developer Mode](/images/manual/Picture1.png)

---

3. **Open your Chrome browser**:

   - Click on the **three dots** in the top right corner.

   ![Enable Developer Mode](/images/manual/Picture2.png)

   - Select **Manage Extensions**.

   ![Enable Developer Mode](/images/manual/Picture3.png)

   - Toggle **Developer Mode** ON (top right corner of the page).

   ![Enable Developer Mode](/images/manual/Picture4.png)

---

4. **Install the extension**:

   - Open the extracted `.crx` folder.
   - Locate the `.crx` file (shared with you via email).
   - **Drag and drop** the `.crx` file into the Chrome Extensions page.

   ![Enable Developer Mode](/images/manual/Picture5.png)

---

5. **Whitelist the extension**:

   - Run the `extensionWhitelist.reg` file by double-clicking it.

   ![Enable Developer Mode](/images/manual/Picture6.png)

---

6. **Finalize installation**:

   - Restart your Chrome browser.
   - Go to **Manage Extensions**.
   - Ensure the **AlphaSaaS Discovery** extension is **enabled**.

   ![Enable Developer Mode](/images/manual/Picture7.png)
