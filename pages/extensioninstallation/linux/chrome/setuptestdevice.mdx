# Test Device Setup for Chrome Extension Deployment

## PREREQUISITES

- Admin access to the Google Admin Console.
- A Chrome device enrolled in your domain.

---

## 1. Create Test Organizational Units (OUs)

**Purpose**: Segment users and devices for testing policies.

**Steps**:

- Go to **Admin Console > Directory > Organizational Units**
- Click **+** to create a new OU.
- Name it something like `ChromeTest OU`
- Place it under your main domain (e.g., `AlphaSaas`).
- This OU will be used to enroll test browsers and apply experimental policies.
- Save and finish creation.

## 2. Turn on Browser Reporting

**Purpose**: Enable visibility into Chrome browser usage, versions, extensions, and activity.

**Steps**:

- Go to **Admin Console > Chrome browser > Setup Guide > Turn on browser reporting**
- Select your OU: `ChromeTest OU`
- Toggle **Enable managed browser cloud reporting**
- Click **Next**, then **Done**
- Reporting will now capture Chrome version, extension usage, and browser activity for enrolled devices.

## 3. Enroll a Test Browser

**Purpose**: Connect a browser to your Google Admin policies using a token-based method.

**Steps**:

- In **Setup Guide**, click **Enroll a Test Browser**
- Choose **Yes** for using a separate test device
- Select the organizational unit `ChromeTest OU`
- Download the `.reg` file (for Windows) or follow instructions for your OS
- Install the Chrome browser if not already present
- Run the `.reg` file or token method to inject the enrollment token
- Relaunch Chrome — it should now show **“Managed by yourdomain.com”**
- Confirm the enrollment by checking **Managed Browsers** in the Admin Console

## 4. Set Browser Policies

**Purpose**: Apply policies like homepage configuration or Incognito Mode to test behavior.

**Steps**:

- Click **Set Browser Policies**
- Select `ChromeTest OU`
- Configure the following:

  **Browser Homepage**:

  - Allow user to decide
  - OR enforce a specific homepage URL

  **Incognito Mode**:

  - Allow (default)
  - Disallow
  - Force Incognito only

- Click **Save**
- Relaunch the browser on the test device
- Confirm settings are active via `chrome://policy`
