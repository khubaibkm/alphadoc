# Chrome Extension Distribution Guide for Organizations

This guide explains how to distribute the Chrome extension throughout your organization. The extension will be force-installed across all target machines.

---

## Prerequisites

1. **Self-hosted extension URL**: You will receive a link to the extension files from AlphaSaaS, including the `.crx` file and an `update.xml` manifest.
2. **Administrator privileges** on user machines to configure policies.
3. **Chrome Browser** installed on all target machines.

---

## Step 1: Obtain the Extension Links

You will receive the following from AlphaSaaS:

- **Extension ID**
- **Update Manifest (update.xml) URL** (e.g., `https://yourdomain.com/extensions/update.xml`)

---

## Step 2: Distribute the Extension Using Group Policy (Windows)

### 2.1 Ensure Group Policy is Installed

- **Windows Professional or Enterprise**: Group Policy Editor (`gpedit.msc`) is built-in.
- **Windows Home**: You may need to enable Group Policy manually or use the registry method (see Step 3).

### 2.2 Download Chrome Policy Templates

1. Download the **Chrome Enterprise Policy Templates**.
2. Extract the ZIP and navigate to the `policy_templates` folder.
3. Use the appropriate `.adm` or `.admx` file based on your system.

### 2.3 Import Chrome Policies into Group Policy Editor

1. Open **Local Group Policy Editor** (`gpedit.msc`).
2. Go to:

```
Local Computer Policy > Computer Configuration > Administrative Templates
```

3. Right-click **Administrative Templates** and choose **Add/Remove Templates**.
4. Browse to the folder with Chrome policies and add the `chrome.adm` file.

### 2.4 Configure Chrome Extension Force-Install Policy

1. Navigate to:

```
Computer Configuration > Administrative Templates > Google > Google Chrome > Extensions
```

2. Double-click **Configure the list of force-installed apps and extensions**.
3. Select **Enabled**.
4. Click **Show** to add your extension to the list.
5. Use this format:

```
your_extension_id;https://yourdomain.com/extensions/update.xml
```

6. Replace `your_extension_id` with the actual ID.
7. Click **OK** and exit Group Policy Editor.

## Step 3: Distribute the Extension Using the Windows Registry (Windows Home)

### 3.1 Open the Registry Editor

- Press `Win + R`, type `regedit`, and press Enter.

### 3.2 Add the Extension to the Force-Install List

1. Navigate to:

```
HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Google\Chrome\ExtensionInstallForcelist
```

If the `Google` or `Chrome` keys don't exist, create them manually.

2. Right-click in the right-hand pane and select **New > String Value**.
3. Name the string value as `1`, `2`, etc.
4. Set its value as: 5. Close the Registry Editor and restart Chrome.

```
your_extension_id;https://yourdomain.com/extensions/update.xml
```

## Step 4: Verifying Installation

1. After policies are applied, restart Chrome on client machines.
2. Visit `chrome://extensions/` to verify that the extension is installed and enabled.
3. Visit `chrome://policy/` and click **Reload Policies** to check the policy status.

## Step 5: Updating the Extension

AlphaSaaS will handle updates by:

- Providing a new `.crx` file
- Updating the `update.xml` file

As long as the update URL remains the same, the extension will update automatically on all user machines.

## Troubleshooting

### Extension Not Installing?

- Ensure the `update.xml` URL is correct and accessible from all client machines.
- Confirm that Chrome is restarted after applying policies.

### Cannot Access Chrome Policies?

- Ensure you have administrator privileges on the machine.
- Verify that Chrome's group policies or registry settings have been applied correctly.
